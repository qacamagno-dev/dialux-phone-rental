Where the cheap points are

Ordered by effort, not by checklist position — what buys the most ticks per hour of work.

~1 hour

Add the Users tab to the admin dashboard

The hardest part is already done — GET /api/users and PATCH /api/users/:id/role work today. This needs a usersApi method and a fifth tab, and it converts checklist item III-5 from a gap into a tick.

~2 hours

Write the six missing static pages

About, Team, Contact, Help, Terms, Privacy are already linked from the footer and currently go nowhere. A contact form on contact.html also closes II-6, and an FAQ covers part of the support requirement.

~2 hours

Deploy it

MongoDB is already on Atlas, and Express already serves the frontend — so one host handles both. Make the API base URL in js/core/api.js:12 environment-aware, then push. A live URL demos far better than localhost.

~3 hours

Wishlist, end to end

An array of product ids on the User model, two endpoints, a heart button on the product card, and a section in the profile page. Closes II-2 and, if you build the mobile app, IV-8 too.

Decision

The mobile app — 40 items, or a scope conversation

This is the single largest gap and cannot be squeezed in late. Either commit to it as its own build, or agree with your professor that the responsive web app satisfies section IV. Worth settling before anything else on this list.
